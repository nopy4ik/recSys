# Авто по вкусу

Небольшое учебное приложение для лабораторной №5 по рекомендательным системам. Оно рекомендует автомобили по совместным положительным предпочтениям пользователей (item-to-item collaborative filtering) и ранжирует варианты с помощью PMI.

## Запуск

Нужен Python 3. Запускать зависимости через `pip` не нужно.

```bash
python3 app.py
```

Откройте в браузере <http://127.0.0.1:8765>. Остановить сервер можно сочетанием `Ctrl+C`.

## Как пользоваться

1. Выберите пример синтетической истории выбора покупателя.
2. При необходимости задайте бюджет и тип кузова.
3. Нажмите «Показать подборку».
4. Сравните рекомендации и пояснения PMI с автомобилями, которые уже понравились профилю.

## Алгоритм

Положительные предпочтения хранятся как бинарная матрица «профиль — автомобиль». Для каждой пары автомобилей считаются число профилей с обоими автомобилями `n_xy`, число профилей с каждым отдельным автомобилем `n_x` и `n_y`, а также общее число профилей `N`.

```text
PMI(x, y) = log2(n_xy * N / (n_x * n_y))
```

Оценка кандидата — среднее PMI между ним и автомобилями, которые уже понравились выбранному профилю. Уже выбранные автомобили исключаются из рекомендаций. Бюджет и тип кузова применяются как фильтры перед показом списка.

## Данные и ограничения

Истории профилей, цены и характеристики автомобилей в приложении синтетические. Это демонстрационный набор для лабораторной, а не актуальная база объявлений. Фильтр бюджета и кузова не входит в PMI и не влияет на совместные частоты.

В репозитории также лежат методические указания, лекция и слайды в PDF.
