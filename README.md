# Авто по вкусу

Небольшое учебное приложение для лабораторной №5 по рекомендательным системам. Оно рекомендует автомобили по совместным положительным предпочтениям пользователей (item-to-item collaborative filtering) и ранжирует варианты с помощью PMI.

## Запуск

Нужен Python 3. Запускать зависимости через `pip` не нужно.

```bash
python3 app.py
```

Откройте в браузере <http://127.0.0.1:8765>. Остановить сервер можно сочетанием `Ctrl+C`.

## Как пользоваться

1. Укажите бюджет и нужные характеристики: марку, кузов, год, мощность, топливо, коробку передач и привод.
2. Нажмите «Подобрать автомобили».
3. Сравните подходящие варианты и пояснения PMI.

## Алгоритм

Готовая база положительных предпочтений хранится как бинарная матрица «покупатель — автомобиль». Введённые параметры отбирают подходящие автомобили в каталоге; затем они ранжируются по средней PMI-связи с остальными подходящими автомобилями из матрицы. Для пары автомобилей считаются число покупателей, которым понравились оба автомобиля `n_xy`, число покупателей с каждым отдельным автомобилем `n_x` и `n_y`, а также общее число покупателей `N`.

```text
PMI(x, y) = log2(n_xy * N / (n_x * n_y))
```

В интерфейсе 8 параметров: максимальный бюджет, марка, кузов, минимальный год выпуска, диапазон мощности, тип топлива, коробка передач и привод. Они используются как фильтры каталога; в рекомендацию попадают только автомобили, соответствующие всем выбранным ограничениям. Если после фильтрации для автомобиля не находится пара с общей положительной оценкой, интерфейс показывает число положительных оценок вместо PMI.

## Данные и ограничения

Истории предпочтений покупателей, цены и характеристики автомобилей в приложении синтетические. Это демонстрационный набор для лабораторной, а не актуальная база объявлений. Фильтр бюджета и кузова не входит в PMI и не влияет на совместные частоты.

В репозитории также лежат методические указания, лекция и слайды в PDF.
