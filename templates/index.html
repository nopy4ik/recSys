Как формируется список

Для каждой пары автомобилей PMI считается по готовой матрице предпочтений других покупателей. Для вашего выбора оцениваем связь с каждым отмеченным автомобилем и ранжируем кандидатов по среднему значению.

PMI(x, y) = log₂ (nₓᵧ · N / nₓ · nᵧ)
